# Phase 1 required failure demonstrations (brief section 6.3)

Generated by: `bash scripts/failure-demos.sh` — guided; it pauses and tells you
which teammate must stop which service.

| File | Scenario |
|---|---|
| `1-wrong-dns-server.txt` | client points at a dead resolver |
| `2-dns-wrong-ip.txt` | DNS resolves, but to the wrong address |
| `3-one-backend-down.txt` | Backend A stopped; service continues on B |
| `4-both-backends-down.txt` | both stopped; edge healthy, 502 |
| `5-wrong-port.txt` | right host, nothing listening on that port |

The point of each is not that something breaks — it is that it breaks at ONE
identifiable layer while the layers below keep working.
